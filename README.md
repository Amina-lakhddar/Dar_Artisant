## Présentation de projet :
Ce projet est un site e-commerce s'appelle Dar l'Artisant. Il permet de présenter :
- ### Page d’accueil

La page d’accueil présente les catégories populaires, les produits vedettes et les principaux avantages de Dar l’Artisan, avec une navigation simple et un design inspiré de l’artisanat marocain.
- ### Page Catalogue

La page catalogue présente les produits artisanaux marocains avec leurs images, leurs noms, leurs prix et un bouton « Ajouter au panier » pour faciliter les achats.
- ### Page Détail du produit

Cette page présente les informations détaillées d’un produit artisanal, notamment son prix, sa catégorie, sa matière, ses dimensions, sa disponibilité et sa description, avec un bouton pour l’ajouter au panier.

- ### Page Contact

Cette page permet aux clients de consulter les coordonnées de Dar l’Artisan, de découvrir sa localisation et de nous contacter via un formulaire.

- ### Page À propos

Cette page présente l’histoire de Dar l’Artisan, ses valeurs, son engagement et sa mission de préserver et de valoriser le patrimoine artisanal marocain.
- ### Page Panier

Cette page présente une maquette statique du panier, avec des produits, des quantités, un récapitulatif de commande et des suggestions de produits complémentaires.

## Installation du projet

1. Cloner le dépôt GitHub

    git clone https://github.com/Amina-lakhddar/Dar_Artisant.git

2. Accéder au dossier du projet

    cd Dar_Artisant

3. Installer les dépendances

    npm install

4. Lancer le projet

    Ouvrir le fichier index.html dans un navigateur, ou utiliser l’extension Live Server de VS Code pour visualiser le site.

5. Consulter le site

    Parcourir les différentes pages : Accueil, Catalogue, Détail du produit, À propos, Contact et Panier.
